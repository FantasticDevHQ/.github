# Getting help

Fantastic.Dev projects are maintained in the open on a best-effort basis. There
is no paid support or guaranteed response time.

## Start here

1. **Read the project's README.** Its **Quick start** has manual setup and a
   "Have my agent set this up" prompt you can paste into your coding agent.
2. **Check the project's `docs/` folder** for configuration and reference.
3. **Search existing issues**, including closed ones.

## Ask a question

Ask usage questions in
[Fantastic.Dev Discussions](https://github.com/FantasticDevHQ/.github/discussions/categories/q-a).
Include the project, version, what you tried and what happened.

## Report a problem

Open an issue in the relevant repository and choose the form that fits:

| Form | Use it when |
| --- | --- |
| Bug report | The project does not behave as documented |
| Agent setup problem | Your coding agent could not follow the README setup prompt |
| Documentation | Docs are wrong, missing or unclear |
| Feature request | You need something the project does not do yet |

Security problems never go in public issues; follow the
[security policy](SECURITY.md).

## Stay up to date

Watch a repository's releases on GitHub, or follow
[Fantastic.Dev](https://fantastic.dev),
[YouTube](https://www.youtube.com/@FantasticDevHQ) and
[Twitter / X](https://twitter.com/FantasticDevHQ).
